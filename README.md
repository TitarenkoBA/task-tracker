# Task Tracker

Простой и удобный трекер задач в духе Jira, который работает **прямо в браузере и без сервера**.

- 📋 **Доска (канбан)** с перетаскиванием карточек — мышью и пальцем
- 🗂 **Бэклог и спринты**: планирование, старт, завершение с переносом незавершённых задач
- 🧩 **Типы задач**: эпик, история, задача, баг, подзадача; приоритеты, метки, story points, сроки
- 💬 **Комментарии и история изменений** у каждой задачи
- 🔎 **Поиск и фильтры** по всем задачам (проект, статус, исполнитель, тип, приоритет, метка)
- 📱 **Mobile first**: нижняя навигация, «шторки» вместо модальных окон, свайп колонок доски
- 📝 **Markdown** в описаниях и комментариях: заголовки, списки, чек-листы, ссылки, код — с панелью кнопок и предпросмотром
- 🌍 **Русский и английский** интерфейс, переключение на лету в «Настройках»
- 🌙 Светлая и тёмная тема
- 📦 **PWA**: устанавливается как приложение, работает офлайн
- 💾 **Все данные хранятся локально** (IndexedDB). Экспорт/импорт в JSON, выгрузка задач в CSV
- 🤝 **Совместная работа в реальном времени (P2P)**: пригласите людей по ссылке — задачи, доска и комментарии синхронизируются мгновенно, напрямую между браузерами, без сервера с данными. Офлайн-правки сливаются при подключении. См. [docs/p2p-sync.md](docs/p2p-sync.md)
- 💬 **Чат проекта**: история хранится на устройстве и синхронизируется с участниками
- 🛡 **Обновления не теряют данные**: схема базы меняется только добавлением, это проверяется тестами

## Быстрый старт

Нужен [Node.js](https://nodejs.org) 22 или новее.

```bash
npm install      # установить зависимости (один раз)
npm start        # запустить для разработки → http://localhost:4200
```

Откройте приложение и нажмите **«Открыть демо-проект»**, чтобы сразу увидеть всё в деле.

## Команды

| Команда                | Что делает                                                     |
| ---------------------- | -------------------------------------------------------------- |
| `npm start`            | Сервер разработки с автообновлением                            |
| `npm run build`        | Продакшн-сборка в `dist/task-tracker/browser` (с Service Worker) |
| `npm test`             | Тесты в режиме наблюдения                                      |
| `npm run test:ci`      | Тесты один раз (для CI)                                        |
| `npm run format`       | Отформатировать код (Prettier)                                 |
| `npm run format:check` | Проверить форматирование                                       |

## Публикация

Каждый push в `main` автоматически проверяется (форматирование, тесты), собирается и публикуется на
GitHub Pages через GitHub Actions. Первая настройка занимает пару минут — см. [docs/deployment.md](docs/deployment.md).
