# Руководство пользователя

## Основные понятия

Если вы работали с Jira — всё будет знакомо. Если нет, вот словарик:

| Понятие | Что это |
| --- | --- |
| **Проект** | Контейнер для задач, например «Сайт» или «Мобильное приложение». У проекта есть короткий **ключ** (`WEB`), из которого строятся номера задач: `WEB-1`, `WEB-2`… |
| **Задача** | Единица работы. У каждой есть тип, статус, приоритет, исполнитель и т.д. |
| **Тип задачи** | **Эпик** — большая цель, объединяющая несколько задач. **История** — функция с точки зрения пользователя. **Задача** — техническая работа. **Баг** — ошибка. **Подзадача** — шаг внутри задачи. |
| **Статус** | Где задача находится в рабочем процессе: «К выполнению», «В работе», «На проверке», «Готово». Статусы = колонки доски, их можно настроить. |
| **Бэклог** | Список всех задач, которые ещё не взяты в спринт. Порядок в списке = приоритет. |
| **Спринт** | Отрезок времени (обычно 1–2 недели), на который команда берёт набор задач. |
| **Story points** | Условная оценка сложности задачи. Сумма по спринту помогает не перегрузить его. |

## Навигация

- **На телефоне** — нижняя панель: Обзор, Доска, Бэклог, Задачи, Ещё (настройки). Кнопка **«+»** справа внизу создаёт задачу.
- **На компьютере** — меню слева. Под текущим проектом есть ссылки на его доску, бэклог и настройки.
- Переключить проект можно, нажав на его название под заголовком страницы.

### Горячие клавиши (на компьютере)

| Клавиша | Действие |
| --- | --- |
| <kbd>C</kbd> | Создать задачу |
| <kbd>/</kbd> | Поиск задач |
| <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Отправить комментарий |
| <kbd>Enter</kbd> | Сохранить название задачи / добавить подзадачу или задачу в бэклог |
| <kbd>Esc</kbd> | Закрыть диалог |

## Типичный сценарий работы

1. **Создайте проект** (Проекты → «+ Проект»). Ключ предложится автоматически по названию.
2. **Наполните бэклог.** На странице «Бэклог» внизу списка есть поле быстрого добавления: напишите название и нажмите Enter.
3. **Создайте спринт** («+ Спринт») и **перетащите** в него задачи из бэклога.
4. **Начните спринт** — выберите длительность и цель.
5. Работайте на **доске**: перетаскивайте карточки между колонками по мере выполнения.
   На телефоне колонки листаются свайпом, а чтобы взять карточку — **нажмите и подержите** её.
6. **Завершите спринт** в бэклоге: незавершённые задачи можно перенести в следующий спринт или обратно в бэклог.

> Не хотите спринтов? Просто не создавайте их — доска покажет все задачи проекта (режим «Канбан»).

## Страница задачи

Откройте задачу кликом по карточке. Здесь всё редактируется **на месте и сохраняется сразу**, кнопки «Сохранить» нет:

- название — кликните и правьте; Enter сохраняет;
- статус — большой цветной переключатель вверху;
- поля справа (на телефоне — под названием): исполнитель, приоритет, тип, спринт, эпик, метки, story points, срок;
- **Подзадачи** — чек-лист внизу: кружок слева переключает «готово / не готово»;
- **Комментарии** и **История** — вкладки внизу. История фиксирует, кто, когда и что поменял.

Ссылку на задачу можно скопировать кнопкой 🔗 — адрес вида `/browse/WEB-12` всегда ведёт к этой задаче.

## Поиск и фильтры

Страница **«Задачи»** показывает задачи всех проектов. Поиск ищет по ключу, названию, описанию и меткам.
Кнопка **«Фильтры»** открывает выбор проекта, статуса, исполнителя, типа, приоритета, метки и сортировки.
Фильтры запоминаются, пока открыто приложение.

На доске и в бэклоге есть свои быстрые фильтры: поиск, аватары участников, «Только мои», эпики.

## Участники

В «Настройках» можно задать своё имя и добавить других людей, чтобы назначать их исполнителями.
Пока это просто «карточки» — когда появится совместная работа, участники станут реальными пользователями.

## Резервная копия и перенос на другое устройство

Данные хранятся **только в этом браузере**. Чтобы не потерять их или перенести:

1. **Настройки → Экспорт (JSON)** — скачается файл `task-tracker-ГГГГ-ММ-ДД.json`.
2. На другом устройстве: **Настройки → Импорт** и выберите файл.
3. Выберите режим:
   - **Объединить** (рекомендуется) — ничего не теряется. Если одна и та же задача менялась на обоих устройствах,
     для каждого поля остаётся более позднее изменение. Удалённые на одном устройстве задачи удалятся и на другом.
   - **Заменить всё** — текущие данные удаляются и заменяются файлом.

**Задачи в CSV** — выгрузка таблицы задач для Excel или Google Таблиц (только экспорт).

> Совет: нажмите **«Защитить»** в разделе «Данные», чтобы браузер не удалял данные при нехватке места.
> Установленное приложение (PWA) обычно защищено автоматически.
