# Начало работы

Этот документ — для тех, кто впервые открывает проект. Здесь нет ничего, что нужно знать заранее, кроме умения открыть терминал.

## 1. Что нужно установить

1. **Node.js 22+** — среда, в которой работают инструменты сборки. Скачайте LTS-версию с [nodejs.org](https://nodejs.org).
   Проверить установку: `node -v` (должно показать `v22…` или новее).
2. **Git** — система контроля версий. [git-scm.com](https://git-scm.com).
3. **Редактор кода.** Рекомендуем [VS Code](https://code.visualstudio.com). При открытии проекта он предложит
   расширение Angular Language Service — установите его, оно подсказывает ошибки прямо в шаблонах.

## 2. Первый запуск

```bash
npm install   # скачивает зависимости в папку node_modules (1–2 минуты, один раз)
npm start     # запускает сервер разработки
```

Откройте <http://localhost:4200>. При сохранении любого файла страница обновится сама.

> **Подсказка.** На странице «Обзор» нажмите «Открыть демо-проект» — появятся проект, спринт, задачи и
> участники. Так проще понять, как всё связано.

### Открыть с телефона

Телефон и компьютер должны быть в одной Wi-Fi сети:

```bash
npx ng serve --host 0.0.0.0
```

Затем на телефоне откройте `http://<IP-компьютера>:4200`. IP можно узнать командой `ipconfig` (Windows)
или `ifconfig` (macOS/Linux).

## 3. Структура папок (коротко)

```
src/
├── index.html            Единственная HTML-страница
├── styles.css            Глобальные стили и тема Tailwind
├── main.ts               Точка входа
├── testing/              Помощники для тестов
└── app/
    ├── app.ts / app.html Оболочка: меню, нижняя навигация, кнопка «+»
    ├── app.config.ts     Настройка приложения (роутер, Service Worker, инициализация)
    ├── app.routes.ts     Список страниц и их адресов
    ├── core/             Данные, бизнес-логика и переводы (core/i18n)
    ├── shared/           Переиспользуемые UI-компоненты (иконки, аватары, диалоги)
    └── features/         Экраны: доска, бэклог, задача, настройки…
public/                   Иконки и манифест PWA (копируются в сборку как есть)
docs/                     Документация
```

Подробно — в [architecture.md](architecture.md).

## 4. Сборка для публикации

```bash
npm run build
```

Готовый сайт появится в `dist/task-tracker/browser`. Это обычные статические файлы — их можно выложить
на любой хостинг: GitHub Pages, Netlify, Vercel, Cloudflare Pages, свой nginx.

Важно для хостинга:

- **HTTPS обязателен** для PWA (Service Worker не работает по `http`, кроме `localhost`).
- **Все неизвестные адреса должны отдавать `index.html`** (так называемый SPA fallback),
  иначе обновление страницы `/browse/WEB-1` покажет 404. В Netlify это файл `_redirects`
  со строкой `/* /index.html 200`, в nginx — `try_files $uri /index.html;`.
- Если сайт лежит не в корне домена (например, `https://user.github.io/task-tracker/`),
  собирайте так: `npx ng build --base-href /task-tracker/`.

## 5. PWA: установка и офлайн

В продакшн-сборке включается Service Worker (`ngsw-config.json`). Он кэширует приложение, поэтому после
первого открытия всё работает без интернета.

- **Установить на телефон:** в браузере меню → «Добавить на главный экран» (Safari: «Поделиться» → «На экран „Домой“»).
- **Установить на компьютер:** иконка установки в адресной строке Chrome/Edge или кнопка в «Настройках» приложения.
- **Обновления:** когда выходит новая версия, сверху появится плашка «Доступна новая версия → Обновить».

В режиме разработки (`npm start`) Service Worker выключен, чтобы не мешать.

## 6. Где хранятся данные

В **IndexedDB** браузера — это встроенная база данных. Данные:

- не уходят ни на какой сервер;
- привязаны к адресу сайта и браузеру (в другом браузере — другие данные);
- могут быть удалены браузером при нехватке места или очистке истории.

Поэтому в «Настройках» есть **экспорт в JSON** (резервная копия) и кнопка **«Защитить»**, которая просит
браузер не удалять данные автоматически. Посмотреть содержимое базы можно в DevTools браузера:
вкладка *Application → IndexedDB → task-tracker*.

## 7. Частые проблемы

| Симптом | Что делать |
| --- | --- |
| `npm install` падает с ошибками доступа | Закройте редактор/антивирус, удалите `node_modules` и повторите |
| Порт 4200 занят | `npx ng serve --port 4300` |
| После деплоя открывается старая версия | Это кэш Service Worker. Подождите плашку «Обновить» или обновите страницу дважды |
| Пропали данные | Проверьте, тот ли это браузер и адрес. Восстановите из JSON-экспорта в «Настройках» |
